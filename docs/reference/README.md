# Reference material (external sources)

External texts kept for design inspiration — **not project docs, not current state.** Don't load
these into working context unless a task specifically calls for design research.

- **Procedural Content Generation in Games** (Shaker, Togelius, Nelson) — textbook, split by chapter.
  Relevant for dungeon/level/quest generation (ch. 3, 7), mechanics (ch. 6), evaluation (ch. 12).
- **RTOR — Roguelike Theory of Relativity** (Nathan Daniels) — roguelike design essay.

Project design research lives separately in `docs/research/` (that's our own notes, with an INDEX).
